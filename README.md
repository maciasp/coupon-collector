### coupon-collector

#### Soluciones para el problema del coleccionista de cupones usando números pseudoaleatorios

Este software consiste en una serie de simulaciones que simulan este problema visto desde distintos ángulos. Consiste en tres archivos html, cada uno de ellos con distintas funciónes. Todos ellos están escritos en html/Javascript.

El propósito es el de analizar el problema del coleccionista de cupones desde otros puntos de vista, comprobando de paso la validez de la aproximación.

#### Modo de empleo

Para usar basta con descargar cualquiera de los tres y ejecutar desde un navegador, bien sirviendo los archivos o ejecutándolos directamente.

#### Descripción de las simulaciones

1.**sim1.html** Esta simulación permite usar distintos algoritmos para generar números pseudoaleatorios, comprobando además la validez de los mismos para esta aplicación. También recrea el cálculo de expectativas y lo coteja con el modelo teórico, tanto los resultados del cálculo como visualmente.

2.**sim2.html** El propósito de esta simulación es recrear la colección en una población determinada para visualizar las estrategias mas obvias para un coleccionista.

3.**sim3.html** Esta simulación permite iterar colecciones, no genera ningún cálculo. El propósito es generar tablas para un posterior análisis de los datos generados.
